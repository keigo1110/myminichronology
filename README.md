# ミニクロ

Excel ファイルにまとめた **年 / 範囲 / 出来事** のデータを読み込み、**縦スクロール型の年表** としてブラウザ上に表示し、A4 横向き PDF へエクスポートできる Web アプリです。

## 機能

- **Excel ファイル読み込み**: `.xlsx` をドラッグ & ドロップ / ファイル選択
- **年表可視化**: 点イベント（円）と期間イベント（縦バー）
- **レーン操作**: 最大 5 シート、表示切替・並び替え
- **年代フィルタ**: ズーム（再レイアウト）/ フィルタ（位置維持）モード
- **PDF エクスポート**: A4 横向き
- **年間高さ調整**: 8px〜120px
- **読み込み警告**: スキップ行・シート切り捨てなどを画面に表示

## セットアップ

### 前提条件

- Node.js 18.0.0 以上
- npm

### インストール

```bash
git clone <repository-url>
cd myminichronology
npm install
```

### 開発サーバー

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

開発者向けの詳細は [DEVELOPMENT.md](./DEVELOPMENT.md) を参照してください。

## 使い方

1. Excel（`.xlsx`、最大 10MB）をドロップ、またはヘッダーのアップロードボタンから選択
2. 必要なら年代範囲・レーン表示を調整
3. 「PDF エクスポート」でダウンロード

テンプレート: [public/template.xlsx](./public/template.xlsx)

## データ形式

| 列 | 内容 | 必須 |
| --- | --- | --- |
| A | 年（開始年） | ✔ |
| B | いつまで（終了年） | 任意（空なら点イベント） |
| C | 出来事 | ✔ |
| D | フォントサイズ（px） | 任意（空なら既定 11px） |
| E | 色（文字色） | 任意（空なら黒 `#000000`） |

**色の書き方:** `#C45C26` または `C45C26`（3桁/6桁の16進）。無効値は警告のうえ黒になります。

**注意:**

- 先頭から最大 **5 シート**（レーン）まで。超過分は警告付きでスキップ
- 年は 1〜9999、全体の年幅は 2000 年以内
- フォントサイズは 8〜48（px）
- 1 行目はヘッダーとして扱います

## トラブルシューティング

1. **Excel が読み込めない**  
   `.xlsx` か、必須列（年・出来事）があるか、10MB 以下かを確認してください。

2. **行が足りない / 警告が出る**  
   無効な年・空行・6 シート目以降はスキップされ、警告が表示されます。

3. **PDF が空白 / 失敗する**  
   非常に長い年表はブラウザのキャンバス制限に当たることがあります。年代範囲を絞って再試行してください。

4. **年表がずれるように見える**  
   ズームモードではフィルタ後の年範囲で再レイアウトされます。全体位置を保ちたい場合は「フィルタ」モードを使ってください。
