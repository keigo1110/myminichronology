# Excel テンプレート列仕様

入力ファイル（`.xlsx`）の各シートは 1 レーンです。1 行目はヘッダー、2 行目以降がイベントです。

テンプレート本体:

- 利用者向け見本: [`public/template_sample.xlsx`](../public/template_sample.xlsx)（警告の出ないきれいな例）
- 開発・目視検証用: [`public/template_test.xlsx`](../public/template_test.xlsx)（境界値・無効スタイル・混在パターン）

## 列役割一覧

| 列 | 内容 | 必須 / 任意 | デフォルト |
| --- | --- | --- | --- |
| A | 年（開始年） | 必須 | — |
| B | 出来事 | 必須 | — |
| C | いつまで（終了年） | 任意（空なら点イベント） | なし（点イベント） |
| D | フォントサイズ（px, 8〜48） | 任意 | 現状相当（11px / 縦書き時 12px） |
| E | 色（`#RRGGBB` など） | 任意 | 黒 `#000000` |
| F | 表示スタイル | 任意 | 通常テキスト（空欄） |
| G | 画像リンク（URL） | 任意 | なし |

## 表示スタイル（F列）

| 値 | 意味 |
| --- | --- |
| （空欄） / `default` / `テキスト` | 通常表示。文字のみ。期間イベントは細い期間バー付き |
| `label` / `ラベル` | goal_design 風の**塗りつぶしボックス＋縦書きラベル**。E列はボックスの塗り色。**大きさは文字数（幅＝1文字分、高さ＝文字数）**で決まり、C列の期間は表示サイズ・配置密度に使いません（ツールチップ等のデータとしては残ります） |

## 色（E列）の意味

- **通常表示**: 文字色
- **`label` 表示**: ボックスの塗り色（文字色はコントラストから自動選択）

書き方: `#C45C26` または `C45C26`（3 桁 / 6 桁の 16 進）。`rgb(r,g,b)` も可。

## 画像リンク（G列）

- `http://` または `https://` で始まる画像 URL を入れると、出来事の横（横型の期間は下）にサムネイルを埋め込みます。
- レイアウトは**固定枠**（約 72×54px）を予約するため、実画像の実寸に依存しません。読み込み失敗時も同じ枠に「画像なし」と出します。
- **PDF エクスポート**では、画像サーバーが CORS（`Access-Control-Allow-Origin`）を許可している必要があります。許可がないとキャンバスに取り込めず失敗することがあります。
- `javascript:` / `data:` / 相対パスなどは無効（警告のうえ画像なし）。

## 補足

- **シート名**がレーン名として表示されます（先頭最大 5 シート）。
- 無効なフォントサイズ・色・表示スタイル・画像 URL は警告を出し、デフォルトを使います。
  - 例: F列に `box` など未対応の値 → 「通常表示にします」という警告（行自体は読み込まれる）
- **いつまで（C列）がある期間イベント**は、期間の長さに応じた高さになります（`label` スタイルを除く）。
- 年は 1〜9999、ファイル全体の年幅は 2000 年以内です。
- ファイルサイズ上限は 10MB です。
- `public/template_sample.xlsx` … 利用者向けの見本（無効値なし）
- `public/template_test.xlsx` … 目視・警告確認用（`5_境界値` に意図的な無効スタイル等を含む）
- アプリ画面上で出来事文字列の検索・ジャンプができます。

## 変更時

列を追加・変更したら、このファイルと `public/template_sample.xlsx` / `public/template_test.xlsx`、パーサ（`src/lib/parseExcel.ts`）を同じ変更で更新してください。
