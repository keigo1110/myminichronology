# Excel テンプレート列仕様

入力ファイル（`.xlsx`）の各シートは 1 レーンです。1 行目はヘッダー、2 行目以降がイベントです。

テンプレート本体: [`public/template.xlsx`](../public/template.xlsx)

## 列役割一覧

| 列 | 内容 | 必須 / 任意 | デフォルト |
| --- | --- | --- | --- |
| A | 年（開始年） | 必須 | — |
| B | いつまで（終了年） | 任意（空なら点イベント） | なし（点イベント） |
| C | 出来事 | 必須 | — |
| D | フォントサイズ（px, 8〜48） | 任意 | 現状相当（11px / 縦書き時 12px） |
| E | 色（文字色 `#RRGGBB` など） | 任意 | 黒 `#000000` |

## 補足

- **シート名**がレーン名として表示されます（先頭最大 5 シート）。
- **色**の書き方: `#C45C26` または `C45C26`（3 桁 / 6 桁の 16 進）。`rgb(r,g,b)` も可。
- 無効なフォントサイズ・色は警告を出し、それぞれデフォルトを使います。
- イベントは背景ボックスなしのテキスト表示です。E 列は文字色です。
- **いつまで（B列）がある期間イベント**は、期間の長さに応じた縦バーが付き、幅・高さが視覚的に分かります。
- 年は 1〜9999、ファイル全体の年幅は 2000 年以内です。
- ファイルサイズ上限は 10MB です。

## 変更時

列を追加・変更したら、このファイルと `public/template.xlsx`、パーサ（`src/lib/parseExcel.ts`）を同じ変更で更新してください。
