# 修正後の追加レビュー・検証記録

対象は前回修正後のコード。2026-10-02に、性能・表示の正確性・操作性・異常入力への対応を再確認しました。以下の確認できた問題は修正済みです。

| 問題 | 修正と効果 |
| --- | --- |
| 横型配置が出来事ごとに全件走査・ソートを繰り返す | 終了位置の優先キューと空き領域のAVL木に変更。異なる高さでも従来の配置密度を維持 |
| 期間バーが長い文字や画像の寸法に引っ張られる | 年軸から求めるバー長を表示枠の寸法から分離。検索時の強調も枠寸法を変えない |
| 年代を消して打ち直せない／確定で入力欄が作り直される | 編集中の文字列と確定値を分離。Tabで次の欄へ移動でき、整数以外は直前の値へ戻す |
| 検索結果が固定の年軸・テーマ名に隠れる | 固定部分を除いてスクロール。画面より大きいラベルは先頭から見せる |
| 仮想描画で操作中の出来事が消え、キーボードのフォーカスを失う | フォーカス中の出来事は描画を維持。イベントIDも再利用してスクロール時の処理を削減 |
| PDF生成を途中で止められない | 中止ボタンとAbortSignalを追加。現在のページの描画終了後に後片付けし、後続ページ・保存を止める |
| PDF画像がページごとに再取得される／欠落が伝わらない | URLごとに一度取得してPNGへ固定。取得失敗・タイムアウトは代替表示と保存後の通知へ |
| 不正行が大量にあると警告の表示が重くなる | 詳細は先頭200件＋省略件数。長い入力値は警告内で短縮し、総件数は省略分を含めて表示 |
| 大量の長文でブラウザの描画寸法を超える | 出来事の合計文字数を250,000文字に制限。PDFページ数も計画の配列を作る前に検証 |
| 不完全なフォントサイズ文字列が受理される | 数値または任意のpx接尾辞を含む完全な文字列だけを受理 |
| 小さい画面で設定・ブラウザの操作バーが年表を圧迫する | 動的な画面高さを使用。モバイルの設定欄に高さ上限と内部スクロールを追加 |
| Firefoxで初期描画の不一致が発生する | MUI公式のNext.js 16用キャッシュ連携を追加し、サーバーのCSSをheadへ集約 |
| 中止したファイル読み込みの待機・Workerハンドラーが残る | 待機を中断可能にし、Worker終了時にハンドラーも解放 |

CSSの連携方法は[MUI公式ドキュメント](https://mui.com/material-ui/integrations/nextjs/)に基づきます。依存関係が対応するNode.jsの範囲もpackage.jsonと開発ガイドに反映しました。
