## ミニクロとは

Excel（`.xlsx`）にまとめた年表データを読み込み、ブラウザ上で年表・タイムラインとして可視化し、A4横向きPDFに書き出せる無料のWebアプリです。

複雑な設定は不要。ファイルをドロップするだけです。

**アプリURL:** https://myminichronology.vercel.app/

---

## 年表データの準備

### Excelファイルの形式（列仕様・重要）

1行目はヘッダー、2行目以降が出来事です。**シート名＝レーン名**になります（最大5シート）。

| 列 | 内容 | 必須 |
| --- | --- | --- |
| **A** | 年（開始年） | ✔ |
| **B** | 出来事 | ✔ |
| **C** | いつまで（終了年） | 任意（空＝点イベント） |
| **D** | フォントサイズ（px, 8〜48） | 任意 |
| **E** | 色（`#RRGGBB` など） | 任意（省略時は黒） |
| **F** | 表示スタイル | 任意 |
| **G** | 画像リンク（URL） | 任意 |

> ⚠️ 以前の記事にあった「A=年 / B=いつまで / C=出来事」は **古い仕様** です。現在は **A=年 / B=出来事 / C=いつまで** です。

見本ファイル（アプリの空画面からもダウンロード可）:

- 利用者向け見本: `https://myminichronology.vercel.app/template_sample.xlsx`
- 詳細な列仕様: リポジトリの `docs/excel-template-columns.md`

### F列（表示スタイル）

| 値 | 表示 |
| --- | --- |
| 空欄 / `default` / `テキスト` | 通常テキスト。期間ありなら細い期間バー |
| `label` / `ラベル` | 塗りつぶしボックス＋縦書き。サイズは文字数で決まる（C列の期間は見た目に使わない） |

### G列（画像）

- `https://...` の画像URLを入れると、年表内にサムネイルを埋め込みます
- 画面表示はCORS不要。PDFに含める場合のみ、画像サーバーのCORS許可が必要です

### データ例

シート「政治」

```
年,出来事,(いつまで),フォントサイズ,色,表示スタイル,画像リンク
1945,終戦,,,#5D4037,,
1955,55年体制,1993,12,#1565C0,label,
2011,東日本大震災,,14,#B33A3A,,
```

## 基本的な使い方

### 1. ファイルの読み込み

- 画面に `.xlsx` をドラッグ＆ドロップ  
- またはヘッダーの雲アイコンから選択  

上限: 10MB / シート最大5 / 年幅2000年以内

### 2. 年表の確認と調整

ヘッダーでできること:

- **年間高さ / 年あたりの幅** … スライダーで表示密度を調整（8〜120px）
- **縦横入れ替え** … 「縦：年代・横：テーマ」⇔「縦：テーマ・横：年代（左→右で新）」
- **ダークモード** … 紙面トーンのまま明暗切替
- **言語切替（JA/EN）** … UI文言の日英切替
- **PDFエクスポート** … A4横向き

展開パネル:

- **検索** … いま表示中の出来事だけを検索してジャンプ
- **年代範囲** … 「拡大して再配置」または「位置はそのまま」
- **レーン** … 表示ON/OFFと並び替え（ドラッグ）

### 3. PDF出力

データ読み込み後、PDFアイコンをクリック。  
`timeline-export-[日時].pdf` として保存されます。

## コーディングエージェントでExcelを作る（加筆推奨）

ミニクロは、Cursor などのコーディングエージェントと組み合わせて使うと入力Excelの作成・修正が速くなります。

### なにができるか

- メモ・箇条書き・CSVから、ミニクロ用 `.xlsx` を自動生成
- 警告やエラー文をエージェントに渡して、入力ファイルを修正してもらう

### アプリ側の使い方

1. Excelを読み込む
2. 黄色い**警告**や赤い**エラー**が出たら、アラート右の **コピーボタン** を押す  
   → 「Agent Skill『minikuro-excel-input』向け」の依頼文がクリップボードに入る
3. Cursor（など）のチャットに貼り付けて実行してもらう

### エージェント側（Cursor）での前提

リポジトリに同梱の Skill:

- `.cursor/skills/minikuro-excel-input/`

このSkillは次を知っています:

- 列契約（A〜G）
- `label` / 期間バーの使い分け
- 見本・検証用テンプレートの再生成方法

手動で依頼するときの例:

```
ミニクロ用の年表Excelを作って。
政治・経済・文化の3レーンで、1960〜2020年。
高度成長は label スタイル、オイルショックは期間バー。
Agent Skill「minikuro-excel-input」に従って。
```

または JSON から生成:

```bash
node .cursor/skills/minikuro-excel-input/scripts/generate-xlsx.mjs \
  --out chronology.xlsx --input data.json
```

テンプレート再生成:

```bash
node .cursor/skills/minikuro-excel-input/scripts/regenerate-templates.mjs
```

### うまくいくコツ

- 時代の見出し → F列 `label`（短めの文言）
- 期間の長さを見せたい → C列に終了年、Fは空欄
- 同じ年に出来事が多い → レーンを分ける／文言を短く
- 無効なF列値（例: `box`）は入れない（警告の原因）

## 活用のコツ

- 10年単位など区切りやすい年を使う
- ラベルは簡潔に（年はツールチップ等で分かる）
- 関連イベントは同じシート（レーン）にまとめる
- PCの広い画面で横型表示を試すと、テーマ比較がしやすい

---

## 制限事項

- 対応形式: `.xlsx` のみ（Googleスプレッドシート直読みは非対応。Excel書き出しでOK）
- 最大レーン: 5
- 年: 西暦 1〜9999、全体スパン2000年以内
- ファイル: 10MB以下
- 推奨ブラウザ: 最新の Chrome / Firefox / Safari / Edge
- PC全画面推奨

## トラブルシューティング

**Q. ファイルが読み込めない**  
A. `.xlsx` か確認。A列（年）とB列（出来事）が埋まっているか確認。

**Q. 警告が出る**  
A. 読み込み自体は成功しています。行の補正・スキップの通知です。コピーボタンでエージェントに直せます。

**Q. 画像が出ない**  
A. G列が `https://` の公開URLか確認。PDFに出ない場合は画像ホストのCORSを確認（画面表示はCORS不要）。

**Q. PDFがおかしい / 出ない**  
A. ポップアップやダウンロードブロックを確認。大きな年表は時間がかかります。横に長い年表はページ分割されます。

**Q. 年表が見切れる / 詰まって見える**  
A. 年間高さスライダーを上げる。縦横入れ替えや年代フィルタも試す。

**Q. 英語UIにしたい**  
A. ヘッダーの翻訳アイコンで切替（選択はブラウザに保存されます）。
